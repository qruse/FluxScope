# Signal & Field

A small, static Astro publication about AI, cars, and smart farming. Articles live as portable Markdown or MDX files. Search is generated by Pagefind at build time. There is no app server, database, CMS, or external AI API.

## Local development

Requires Node.js 22.19 or newer; `.node-version` pins the Cloudflare build runtime.

```bash
npm ci
npm run dev
```

Pagefind needs generated HTML. To try search locally:

```bash
npm run build
npm run preview
```

Run the minimum release checks with `npm run check`. This checks Astro/TypeScript and the content schema, builds the site and search index, then checks internal links in the generated HTML. The same checks run during the Cloudflare Pages build.

## Cloudflare Pages

Connect [`qruse/GitBlog`](https://github.com/qruse/GitBlog) to a Cloudflare Pages project with Git integration. Use the `main` production branch, `npm run build` as the build command, and `dist` as the output directory. Set `SITE_URL` in the Pages build environment to the **stable public origin**, such as `https://your-project.pages.dev` or your custom domain. Include `https://` and no path. The build refuses to run on Cloudflare Pages without this value so canonical URLs and sitemap entries cannot silently point at localhost.

Cloudflare Pages will rebuild on pushes to the connected branch. This repository does not need a Cloudflare adapter because all routes are static.

## Publishing an article

1. Add a `.md` or `.mdx` file at `src/content/posts/<category>/<english-slug>.md`. Categories are `ai`, `cars`, and `smartfarm`.
2. Copy the frontmatter shape from an existing post. All fields are required. `image` records a repository image's path, width, height, and descriptive alt text. Use `seoTitle` only when the search title should differ from the visible title. Dates use `YYYY-MM-DD`.
3. Put a direct answer near the top. Make factual claims checkable with links to primary sources close to the relevant text. Include practical limits, useful comparisons, a concise FAQ when appropriate, and a source list. Do not claim firsthand testing unless it happened.
4. Mark unfinished work `draft: true`. Drafts are excluded from routes, RSS, search, and sitemap. Run `npm run check` before merging or pushing.

The content schema is in `src/content.config.ts`. Folder and `category` must match. URLs use the folder and file name, for example `/cars/how-regenerative-braking-works/`. Images are stored in `public/images/` and referenced by a root-relative path.

## Editorial automation

Codex scheduled tasks can propose topics, research sources, draft Markdown, and run checks directly in this repository. Human review should verify citations, dates, image rights, and consequential claims before publication. No OpenAI API key or separate API service is required.

Search Console and GA4 can be added after the public domain is known. The initial build sends no analytics events and loads no advertising code.
