## 3줄 요약

- 64×64m 튜토리얼 섬에 체력·배부름·수분·기력·체온 다섯 가지 상태를 두고, 사람과 AI가 같은 규칙으로 살게 만들었음
- 열매는 다시 안 자라서 섬 식량만으로는 30일을 못 버팀. 실제로 물고기를 한 번도 못 잡은 판은 204판 중 0판이 살아남았음
- 규칙은 두 번 고쳤음. 낚시를 찾기 조금 쉽게 했고, 바다를 훨씬 위험하게 했음

## 섬 하나, 규칙 파일 하나

![튜토리얼 섬을 위에서 본 화면. 가운데 숲과 샘, 북동쪽 바위 언덕이 있고, 해안 물속에 시청자에게만 보이는 낚시터 고리가 있음](/images/stories/hslab-island/part2-map.webp)

*HSL 제작 — 튜토리얼 섬 전경. 물속 고리는 시청자에게만 보이는 숨은 낚시터*

- 지도는 코드로 만듦. 같은 시드로 돌리면 늘 같은 섬이 나옴
- 북동쪽 언덕, 서쪽 샘, 해변 시작점, 언덕 뒤 숨은 동굴이 있음
- 규칙은 `rules.json` 하나에 다 있고, 3D 뷰어(사람 플레이)와 학습용 시뮬레이터가 같은 파일을 읽음
- 그래서 내가 조종할 때와 AI가 학습할 때 배고파지는 속도가 똑같음

| 물건 | 개수 | 얻는 것 |
|---|---|---|
| 야자수 | 9 | 코코넛 3개씩 (배부름 12, 수분 10) |
| 덤불 | 7 | 열매 4개씩 (배부름 8) |
| 나무 | 16 | 4번 치면 나무 1 |
| 바위 | 9 | 2번 치면 돌 1 |
| 풀 | 12 | 섬유 1 |
| 떠밀려 온 나무 | 6 | 나무 1 |

*maps/tutorial.json, rules.json (11/5 기준)*

## 다섯 가지 상태가 계속 줄어듦

- 0.5초가 한 스텝, 하루는 240스텝이고 그중 80스텝이 밤임
- 가만히 있어도 배부름·수분·기력이 줄고, 움직이면 더 줄어듦
- 밤엔 체온이 떨어짐. 동굴 안은 밤에도 따뜻함
- 배부름이나 수분이 0이면 체력이 깎이고, 체력 0이면 끝
- 한 판은 최대 30일

```json
"drainPerStep": { "food": 0.14, "water": 0.23, "energy": 0.17 },
"moveExtra":    { "food": 0.04, "water": 0.04, "energy": 0.08 },
"swimExtra":    { "energy": 0.25, "warmth": 1.5 },
"deepSwimExtra": { "energy": 6 },
"damagePerStep": { "starving": 0.35, "thirsty": 0.6, "cold": 0.3, "exhausted": 0.2 },
"drink": { "spring": 30 },
"craft": { "spear": { "wood": 1, "stone": 1 } }
```

*rules.json 일부 (11/5 기준)*

## 열매는 다시 안 자람

- 처음엔 열매가 일정 시간마다 다시 열리게 했음
- 그랬더니 첫 학습에서 AI가 8분 만에 당시 상한이던 10일을 다 채움. 코코넛을 먹고 낮잠을 자는 습관만으로 살았음
- 그래서 바꿨음. 코코넛이 그렇게 빨리 자랄 리 없으니, 다 먹으면 끝
- 섬 식량을 다 합치면 배부름 548, 시작할 때 80을 더해도 628임
- 깨어 있으면 하루에 34\~43이 줄어듦. 밤에 내내 자도 하루 28쯤이라 30일엔 840 넘게 필요함
- 계산상 섬 식량만으론 보름 남짓이 한계임. 실제 기록도 그렇게 나왔음

![날짜별로 남은 열매와 살아 있는 섬 비율을 그린 선 그래프. 열매는 18일째쯤 거의 바닥나고, 살아 있는 섬은 16일째부터 19일째 사이에 크게 줄어듦](/images/stories/hslab-island/part2-fruit.webp)

*HSL 제작 — 11,000번째 시도의 뇌, 섬 512개, 11/2 (lastday_v3.log)*

- 살아 있는 섬은 16일째 465개에서 19일째 289개로 떨어졌음

## 그래서 숨은 낚시터를 만들었음

- 섬 둘레 물속에 낚시터 3곳을 숨겼음. AI 눈엔 안 보이고, 직접 찔러 봐야 알 수 있음
- 나무 1과 돌 1로 작살을 만들어 물을 찌르면 물고기가 잡힘 (배부름 20)
- 세 곳은 하루에 다시 차는 양이 다름. 낚시터 세 곳을 다 쓰면 하루 최대 배부름 120이라 30일도 가능함

| 낚시터 | 위치 | 하루 회복 | 최대 |
|---|---|---|---|
| 풍족 | 북동쪽 | 3마리 | 6마리 |
| 보통 | 서쪽 | 2마리 | 4마리 |
| 빈약 | 남쪽 (시작점 근처) | 1마리 | 2마리 |

*maps/tutorial.json*

- 11/2 기록에선 이 낚시가 생사를 갈랐음. 물고기를 잡은 308판 중 260판이 30일을 버텼고, 한 번도 못 잡은 204판은 0판이었음

## 바다는 투명 벽이 아님

- 처음엔 깊은 물을 못 들어가게 막았는데, 그러면 바다가 그냥 벽임
- 그래서 깊은 물에 들어갈 수 있게 하되, 기력이 0이 되면 익사하게 했음. 학습 전 AI는 79%가 바다에 빠져 죽었음 (1편)
- 그런데 10/29 규칙은 다 배우고 나면 바다가 너무 안전했음. 만들어 둔 영상을 보니 수영이 별 위험이 없었고, 물 위에서 자기까지 했음
- 11/2에 세 가지를 고치고 Peppo를 처음부터 다시 학습시켰음

| 규칙 | 10/29 | 11/2 |
|---|---|---|
| 물속 체온 감소 (스텝당) | 0.3 | 1.5 |
| 깊은 물 추가 기력 소모 (스텝당) | 0.6 | 6 |
| 시작 기력(90)으로 깊은 물에서 버티는 시간 | 약 8시간 | 약 1.4시간 |
| 물속 수면 | 깊은 물만 금지 | 얕은 물도 금지 |

*rules.json `_water2` (11/2)*

## 하루 한 번 떠밀려 오는 상자

- 하루에 한 번, 아무 때나 해안 어딘가에 상자가 떠밀려 옴
- 2시간(20스텝) 안에 안 열면 바다가 도로 가져감
- 안에는 통조림(배부름 30)이나 그물이 있음. 그물이 있으면 낚시 성공률이 35%에서 60%로 오름
- 섬을 돌아다니는 쪽이 보상을 받게 하려고 넣은 장치임

## AI는 이렇게 봄

![캐릭터 앞쪽 200도로 퍼지는 시야선 24개와 12m 사거리를 그린 도식](/images/stories/hslab-island/part2-rays.webp)

*HSL 제작 — AI가 보는 시야선 24개, 사거리 12m*

- AI는 화면 픽셀을 안 봄. 앞쪽 200도를 시야선 24개로 훑어서, 12m 안에 뭐가 있는지와 물·샘까지의 거리를 받음
- 여기에 자기 상태 다섯 개, 가방 속 물건, 시간, 방향, 바로 앞에 뭐가 있는지 등이 더해져서 입력은 숫자 369개임
- 행동은 13개임. 앞뒤 이동, 좌우 회전, 대각선 이동, 줍기·마시기·찌르기(E), 먹기, 잠, 작살 만들기, 가만히. 여기에 열매만 먹기·코코넛만 먹기가 포함돼 있는데, 기억 실험(4편) 때 추가했고 그 실험 규칙에서만 따로 쓰임

## 난이도는 한 번 낮췄음

- 60분 학습해도 낚시를 끝내 못 배웠음. 1만 번째 이후 단계 평가에선 물고기를 잡은 판이 하나도 없었음
- 작살 만들기, 숨은 지점 앞 물 보기, 찌르기, 35% 당첨이 한 번에 다 맞아야 해서, 우연히 성공할 일조차 거의 없었음
- 그래서 낚시터는 숨긴 채로 두고 두 가지만 바꿨음
- 낚시터 반지름을 3m에서 4.5m로 넓힘
- 낚시터가 아닌 얕은 물에서도 5% 확률로 물고기가 잡히게 함. 낚시터는 여전히 7배 잘 잡힘
- 이것만으로 해결되진 않았음. 바꾼 뒤 15분 학습에서 낚시를 해 본 판은 최대 7.1%였고 (3편), 두뇌를 바꾼 뒤에야 시드별 75\~94%로 올랐음 (4편)

## 다시 한다면

- 규칙 파일을 뷰어와 시뮬레이터가 같이 읽게 한 건 잘한 일이었음. 규칙을 바꿀 때 두 곳이 어긋날 일이 없었음
- 식량 계산은 맵을 만들기 전에 먼저 할 것. 다시 자라는 열매로 시작했다가 너무 쉬운 섬을 한 번 버렸음
- 위험 규칙은 다 배운 AI의 영상으로 다시 볼 것. 처음엔 익사율이 높아서 바다가 충분히 위험하다고 착각했음
- 다음 편은 어떤 강화학습 알고리즘을 쓸지 고른 이야기임
