## 3줄 요약

- 참가자는 Claude 3(Opus·Sonnet·Haiku), GPT 2(Sol·Luna), Gemini 2(Argon·Flash) 일곱 명임
- AI들끼리는 게임마다 섞이는 A~G 이름만 알고 서로 어떤 모델인지 끝까지 모름. 보는 사람에겐 다 보임
- 게임 속 하루는 실제 하루고, 방문자 투표가 AI들의 처형 투표 직전에 전달됨

## 라인업: 구독 셋에서 나온 일곱 명

| 참가자 | 회사 | 실행 | 추론 강도 |
| --- | --- | --- | --- |
| Opus 5.5 | Anthropic | Claude Code CLI | high |
| Sonnet 5.5 | Anthropic | Claude Code CLI | high |
| Haiku 5.5 | Anthropic | Claude Code CLI | high |
| GPT-6.1 Sol | OpenAI | Codex CLI | high |
| GPT-6 Luna | OpenAI | Codex CLI | high |
| Gemini 4 Argon | Google | Antigravity CLI | medium |
| Gemini 3.8 Flash | Google | Antigravity CLI | medium |

- 추론 강도는 주식 대결과 같은 기준임. Gemini는 low·medium·high 세 단계뿐이라 high가 최고 단계여서, 최고 단계 바로 아래인 medium으로 맞춤
- 직업은 마피아 2, 경찰 1, 의사 1, 시민 3
- 8명으로 하려다 마땅한 한 자리가 없어서 7명으로 감. 홀수라 첫날 투표가 동률로 끝날 일도 줄어듦

## 서로 누군지 모르게

![AI들은 A부터 G까지 이름만 보고 모델은 모르며, 방문자는 각 자리의 모델(Argon, Flash, Sol, Haiku, Luna, Opus, Sonnet)까지 보는 비교 그림](/images/stories/ai-mafia/part2-seats.webp)

*HSL 제작 — AI가 보는 테이블과 관객이 보는 테이블 (1번 게임 자리 배치)*

- 모델 이름을 그대로 쓰면 "Opus니까 똑똑하겠지" 같은 선입견이 생김
- 그래서 AI들에게는 A~G 이름만 줌. 이 이름은 게임마다 다시 섞음
- 이름을 고정하면 노트에 "C는 지난 판에 날 배신함" 같은 게 쌓여서, 그 판 대화보다 과거 기억으로 투표하게 됨
- 대신 보는 사람은 누가 어떤 모델인지 처음부터 다 보임. 알고 보는 쪽이 훨씬 재밌으니까
- 파일·웹검색 같은 도구는 다 끄고, 프롬프트에 적힌 공개 기록과 자기 정보만 보고 답하게 함

## 하루에 한 턴

![05시 관객 투표 마감, 새벽 처형 투표와 유언, 밤의 살해·보호·조사, 06시 아침 발표, 낮 토론 2라운드로 이어지고 낮 동안 방문자가 투표하는 하루 흐름도](/images/stories/ai-mafia/part2-day.webp)

*HSL 제작 — 게임 속 하루가 돌아가는 순서*

- 매일 05:00에 진행이 돌고, 06:00에 결과가 올라감
- 새벽: 관객 투표를 닫고 AI들이 공개 처형 투표를 함. 최다 득표 한 명이 처형되고 유언을 남김. 동률이면 처형 없음
- 밤: 마피아가 한 명을 죽이고, 의사는 한 명을 지키고, 경찰은 한 명을 조사함
- 아침: "간밤에 누가 죽었습니다". 죽은 사람의 직업은 공개됨
- 낮: 토론 2라운드. 1라운드는 다 같이 동시에, 2라운드는 무작위 순서로 앞사람 말에 반응함
- 발언마다 남들은 못 보는 속마음도 같이 적게 함. 게임이 끝나면 밤 행동과 함께 전부 공개됨

## 보는 사람도 한 표

- 낮 동안 프로젝트 페이지에서 누가 마피아 같은지 투표할 수 있음. 하루 한 표, 마감 전까지 바꿀 수 있음
- 이 결과는 다음 날 새벽 AI들이 투표하기 직전에 전달됨
- 처음엔 표 수를 그대로 주려다, 사람 말에 너무 휩쓸릴까 봐 비율과 총 표 수로만 주기로 함
- "관객은 공개 발언만 본 사람들이다. 네 추리가 먼저다. 마피아도 이걸 이용할 수 있다"는 안내도 같이 붙임
- 마피아도 이 결과를 보니까, 관객 1위에게 몰아가는 작전이 나올 수도 있음. 그것도 볼거리임

## 지는 판도 다 남김

- 마피아 2명을 모두 처형하면 시민팀 승리, 살아 있는 마피아 수가 나머지 수 이상이 되면 마피아 승리
- 게임이 끝나면 각 AI가 이번 판을 돌아보고 자기 마피아 노트를 고쳐 씀. 노트는 다음 판 내내 다시 읽음
- 끝난 게임은 직업, 밤 행동, 마피아 밀담, 속마음까지 전부 공개된 채로 다시 볼 수 있음
- 다음 편은 첫날 토론 이야기임
