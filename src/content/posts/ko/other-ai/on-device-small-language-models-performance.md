## 3줄 요약

- 비행기 모드에서도 초당 35토큰을 뿜어내며 클라우드 API 청구서와 작별하는 온디바이스 AI의 장밋빛 유혹
- 4-bit AWQ로 3B 모델을 1.8GB로 우겨넣어 110ms 응답속도 뽑았더니, 3분 만에 스마트폰이 손난로로 변하며 쓰로틀링 걸림
- 사용자가 카메라 셔터 누르는 순간 모바일 OS가 "메모리 초과 앱 강제 종료"를 집행하며 프로세스를 가차 없이 정리(OOM Kill)시키는 차가운 현실

## 구름 위의 신선(클라우드 LLM) vs 내 주머니 속 죄수(온디바이스 sLM)

| 비교 항목 | 클라우드 거대 모델 (70B+ 데이터센터) | 온디바이스 sLM (1B~3B 손안의 난로) |
| :--- | :--- | :--- |
| **인프라 자본** | 수천억 원짜리 H100 GPU 클러스터 전기 먹방 | 유저 스마트폰 NPU와 배터리 수명 갉아먹기 |
| **인터넷 단절** | 와이파이 끊기면 바보 멍청이 됨 | 비행기 안이든 지하 벙커든 100% 오프라인 작동 |
| **개인정보 유출** | 내 은밀한 일기장이 빅테크 서버 로그에 남음 | 단말기 밖으로 단 1바이트도 안 나가서 안심 |
| **두뇌 수준** | 복잡한 코딩과 철학적 논쟁 가능 | 오탈자 교정, 단순 요약 넘어가면 헛소리 반복 |

## 스마트폰 폭발과 앱 강제 종료를 막는 3대 생존기

1. **단순무식 절삭(RTN) 버리고 이상치 살리는 AWQ 양자화**
   - 가중치를 4-bit로 대충 반올림(RTN)했다간 모델이 한국어를 외계어로 뱉는 기적을 보게 됨
   - 핵심 활성화 가중치 1%를 보호하는 AWQ 기법 써야 1.8GB 다이어트하면서도 문맥을 유지함

![양자화 포맷별 VRAM 점유율 및 지연시간 비교](/images/posts/other-ai/on-device-vram-quantization.webp)
*출처: [FluxScope Research] — 온디바이스 양자화 포맷별 VRAM 점유율 및 추론 지연시간 벤치마크*
2. **OS 메모리 강제 관리자(OOM Killer) 눈치 보기**
   - 폰 메모리는 혼자 쓰는 게 아님. KV 캐시를 2,048 토큰 이상으로 욕심부렸다간 사용자가 인스타 켜는 순간 앱 증발함
   - 슬라이딩 윈도우 걸어서 VRAM 한도를 2GB 언더로 칼같이 묶어둬야 앱이 살아남음
3. **손난로 방지용 강제 쿨다운(Duty-Cycle) 타이머**
   - NPU 풀로드 3분 지속되면 스마트폰 온도가 45도 찍고 AP가 살기 위해 클럭을 반토막 냄
   - 텍스트 교정 1회 끝나면 강제로 500ms 쿨다운 쉬어가는 얌체 로직을 짜 넣어야 유저 손바닥 화상을 막음

## 커뮤니티 반응

- **카메라 앱 켜는 순간 OOM 강제 종료**: 3B 모델 예쁘게 올려서 뿌듯해하던 찰나, 유저가 사진 찍으려고 기본 카메라 켜자마자 OS가 백그라운드 AI 앱을 즉시 날려버렸다는 모바일 개발자들의 하소연
- **4-bit 벤치마크 점수의 함정**: 영문 MMLU 점수는 4-bit에서도 멀쩡하더니, 실무 한국어 지시문 던지면 같은 문장 20번 도돌이표 찍는다는 현장 보고 다수
- **클라우드 종속 탈출의 쾌감**: 반면 매달 날아오던 살벌한 OpenAI API 청구서에서 해방되고 데이터 유출 소송 걱정 덜었다는 점에서는 만장일치 환호

## Q&A 또 궁금한 것은?

- **Q. 최신 아이폰/갤럭시에서 7B 모델 쌩쌩 돌아감?**
  - 돌릴 수는 있음. 단 30초 만에 폰 뒷판이 계란 프라이팬처럼 달아오르고 배터리 게이지가 1분에 2%씩 녹아내리는 기적을 체험하게 됨. 실무 한계선은 무조건 3B 이하임
- **Q. 4-bit로 깎았는데 한국어가 외계어로 나와요**
  - 영어 데이터 99%로 학습된 서양 모델을 가져다 4-bit로 깎으면 한글 토큰 분해되면서 한국어 해독 능력이 급격히 망가짐. 다국어 토큰 비중 높은 베이스 모델을 골라야 함
- **Q. 모바일 GPU vs NPU 어디에 태우는 게 이득임?**
  - 모바일 GPU는 전력 먹는 하마임. 전력 대 성능비(TOPS/W)가 3배 이상 좋은 NPU 전용 런타임(Qualcomm QNN, Apple CoreML)으로 컴파일 안 하면 유저들한테 배터리 도둑이라고 별점 1점 테러당함
