## 3줄 요약

- 기존 LLM이 생각 없이 입부터 털던 '시스템 1 앵무새'였다면, 추론 모델은 혼자 골방에서 번민하는 '시스템 2 철학자' 코스프레임
- 7중 조인 SQL 정답률은 62%에서 91%로 떡상하지만, 단순 SELECT 1 찍는 데도 12초 동안 우주의 섭리를 고민하느라 API 타임아웃 터짐
- 멍청한 질문까지 생각하게 만들면 다음 달 클라우드 청구서 보고 기절하므로, 무조건 앞단에 뇌 빼기 라우팅 게이트 쳐야 살아남음

## 똑똑해진 척하며 API 비용 태우는 3대 메커니즘

1. **숨겨진 사고 사슬 (Hidden Chain-of-Thought)**
   - 유저한테 답 뱉기 전에 모델 혼자 수백 줄의 독백을 중얼거리며 쉐도우 복싱함
   - "아 잠깐, 이 변수는 널(Null)일 수도 있잖아?"라며 스스로 뺨 때리고 백트래킹(Backtracking)하는 치밀함을 보여줌
   - 문제는 화면에 보이지도 않는 이 독백 토큰까지 엔지니어 법인카드로 꼬박꼬박 결제된다는 잔인한 현실임

2. **트리 탐색 & 프로세스 보상 모델 (PRM)**
   - 몬테카를로 트리 탐색(MCTS) 흉내 내며 그럴싸한 풀이 경로만 골라 파고듦
   - 최종 결론만 보고 대충 채점하던 시절 지나, '풀이의 각 단계마다' 채찍질해서 엉뚱한 삼천포로 빠지는 걸 틀어막음
   - 덕분에 다중 조인 쿼리나 재귀 알고리즘 짤 때 신들린 코딩 실력을 뽐내며 시니어 개발자 밥그릇을 위협함

3. **연산량과 통장 잔고의 정비례 법칙**
   - 질문이 아무리 뻔해도 모델이 필 받으면 수천 토큰씩 내부 연산 돌리면서 장고에 들어감
   - 단순 날짜 포맷 바꾸는 프롬프트 던졌는데 15초 동안 '생각 중...' 깜빡이는 거 보고 있으면 속 터져서 모니터 깰 뻔함

## 헛소리 자판기(전통 LLM) vs 고뇌하는 철학자(추론 모델)

| 비교 항목 | 전통적 범용 LLM (GPT-4o 등) | 추론 전용 모델 (o1 / o3 / R1) |
| :--- | :--- | :--- |
| **사고 체계** | 일단 아무 말이나 빠르게 지어내기 (시스템 1) | 혼자 자책하고 반성하며 오답 고치기 (시스템 2) |
| **응답 지연(TTFT)** | 첫 토큰 0.3초 (성격 급한 한국인 맞춤형) | 최소 10초~30초 (커피 한 잔 마시고 와야 함) |
| **적합한 작업** | 사과문 초안 작성, 뻔한 요약, 단순 챗봇 | 7중 조인 SQL, 커널 취약점 감사, 대형 버그 수정 |
| **청구서 충격** | 토큰당 푼돈 (예측 가능한 수준) | 보이지 않는 사고 토큰 때문에 청구서 폭탄 맞음 |

## 커뮤니티 반응

- **과잉 생각(Overthinking) 대참사**: "오늘 날씨 어때?" 물어봤더니 열역학 제2법칙부터 시작해서 30초 동안 묵념하다 대답한다는 개발자들의 뒷목 잡는 후기 속출
- **보이지 않는 유령 토큰 청구서**: 사용자 화면엔 3줄 출력됐는데 뒷단에서 4,000토큰짜리 자아성찰 독백 돌아서 회사 통장 털렸다는 인프라팀의 절규
- **복잡한 SQL 및 디버깅 찬양**: 반면 레거시 DB 다중 조인 쿼리 던졌을 때 62%에서 91%로 정답률 찍어 누르는 거 보고 "이 녀석은 진짜다"라며 눈물 흘린 엔지니어 속출

## Q&A 또 궁금한 것은?
- **고객 상담 챗봇에 써도 됨?**: 고객이 "배송 언제 와요?" 묻는데 20초 동안 생각하고 있으면 고객센터 불나고 담당자 바로 시말서 씀
- **그럼 어디다 써먹음?**: 다중 테이블 조인 SQL 생성, 레거시 C++ 리팩토링, 보안 취약점 점검처럼 "초 단위 지연보다 1개 오답으로 회사 망하는 게 더 무서운" 고위험 작업에만 핀포인트로 투입해야 함
