## 3줄 요약

- 테슬라가 미국 기준 10월 1일 로드스터를 다시 공개하겠다고 예고함. 공개일이 생겼다는 것과 고객이 차 키를 받는 날이 정해졌다는 건 다른 얘기임
- 유명한 가속 1.9초·주행거리 620마일은 과거 테슬라 발표 수치이고, 미국 일반 예약금은 총 $50,000임. 새 양산차의 검증된 성능이나 최종 판매가로 읽으면 안 됨
- 이번엔 양산 사양, 독립적으로 반복 검증할 수 있는 성능, 구체적인 출고 조건을 봐야 함. 달력은 이미 충분히 시승했음

## 카운트다운은 생겼음. 발표회까지 세는 것임

- 차세대 로드스터는 2017년에 처음 공개됐고 당시 인도 목표는 2020년이었음. 여러 차례 지연된 뒤 이번에는 2026년 10월 1일 공개를 예고한 상태임 ([Reuters, 9월 12일](https://www.reuters.com/business/autos-transportation/tesla-signals-oct-1-launch-long-delayed-roadster-2026-09-12/))
- 9월 28일 확인한 [테슬라 공식 페이지](https://www.tesla.com/roadster)의 카운트다운 목표는 **UTC 10월 2일 00:30, 한국시간 10월 2일 오전 9시 30분**임. 현재 페이지에 설정된 행사 시각이며 변경될 수 있음. 출고 예약 시간이 아님
- 이 글은 행사 전 공개 자료를 읽고 정리한 분석임. 직접 시승한 후기가 아니며, 표지 노트도 확정된 2026년 양산 디자인을 보여주는 실차 사진이 아닌 개념 그림임
- 현장에서 멋진 시연을 보여줄 수는 있음. 그렇다고 고객 차량에 같은 장비가 들어가고 같은 성능을 여러 번 낸다는 것까지 증명되지는 않음. 무대와 우리 집 주차장은 아직 배송지가 다름

## 옛날 제원에는 발표 날짜부터 붙여야 함

| 항목 | 테슬라의 과거 발표 | 새 차에서 확인할 것 |
| :--- | :--- | :--- |
| 가속 | 0–60mph 1.9초 | 양산 사양·타이어·노면·시간 측정 방식 |
| 최고속도 | 250mph 초과 | 실제 측정 결과와 사용한 차량 구성 |
| 주행거리 | 620마일, 약 1,000km로 설명 | 적용한 시험 기준과 양산차 결과 |

*출처: [테슬라 2017년 4분기 업데이트, 2018년 2월 발행, PDF 4쪽](https://ir.tesla.com/_flysystem/s3/sec/000156459018001521/tsla-8k_20180207-gen_0.pdf). 과거 제조사 발표이며 독립 검증된 2026년 제원이 아님*

- **0–60mph와 0–100km/h는 다른 측정 구간임**. 60mph는 약 96.6km/h임. 시간을 그대로 두고 단위만 바꾸면 원래 발표보다 더 센 주장이 됨
- 과거 주행거리 수치를 여기서 EPA나 WLTP 인증값으로 취급하지 않음. 시험 기준부터 확인하지 않고 경쟁차 인증 거리 옆에 놓으면 표는 깔끔해지고 비교는 엉성해짐
- 한 번 빠르게 출발하는 것과 그 성능을 반복하는 것도 다름. 새 차에서는 연속 가속 결과, 배터리 충전 상태·온도, 특수 장비 사용 여부를 보겠음. 확인할 항목이지 직접 측정한 결함 목록이 아님
- 행사에서 특별한 기능을 보여준다면 고객이 받는 차에도 들어가는지, 어떤 조건에서 쓸 수 있는지, 제한은 무엇인지 이어서 봐야 함. 박수 소리로 옵션표의 빈칸을 채울 수는 없음

## $50,000은 차값이 아니라 예약금임

![미국 일반 로드스터 예약금: 카드 $5,000과 10일 이내 송금 $45,000의 구성](/images/posts/mobility/tesla-roadster-reservation-usd.webp)

*출처: [테슬라 미국 예약 페이지](https://www.tesla.com/roadster/reserve), 2026년 9월 28일 확인 — HSL 제작 도표*

- 미국 일반 예약 기준 **카드 $5,000 + 10일 이내 송금 $45,000 = 총 $50,000**임. 테슬라 페이지는 송금이 접수돼야 예약이 확정된다고 설명함
- 이 금액은 예약금임. 새 미국 공식 판매가도, 세금까지 포함한 차량 견적도, 한국 가격도 아님. 예전 기사에 나온 차값을 현재 구매 견적처럼 재활용하지 않겠음
- 실제 예약 전에는 적용되는 계약에서 취소·환불 조건, 정확한 차량 버전, 최종 가격과 인도 조건을 읽어야 함. 돈 보내는 일정은 ‘곧 나옴’보다 훨씬 구체적임

| 이번 행사에서 볼 항목 | 구매 판단을 바꿀 만한 정보 |
| :--- | :--- |
| 양산 버전 | 시연 차량과 고객 차량의 장비 차이가 명확한지 |
| 측정 방식이 있는 성능 | 시간 측정 규칙·시험 조건·반복 결과가 있는지 |
| 기준이 붙은 주행거리 | 어떤 시험과 차량 구성에 해당하는지 |
| 계획할 수 있는 구매 | 최종 가격·생산 및 인도 일정·서면 조건이 있는지 |

- 내 판단 기준은 발표는 즐겁게 보고, 저 정보들이 나오면 평가를 갱신하는 것임. 관심은 바로 가져도 되지만 구매 판단에는 서류가 좀 더 필요함

## Q&A 또 궁금한 것은?

- **Q. 한국에서는 10월 1일에 보면 됨?**
  - 9월 28일 확인한 공식 페이지 카운트다운은 한국시간 10월 2일 오전 9시 30분에 해당함. 일정은 바뀔 수 있으니 행사 직전 공식 페이지를 다시 확인하면 됨
- **Q. 1.9초면 2026년형 제로백이 확정된 것임?**
  - 아님. 인용한 과거 수치는 0–60mph임. 이 글에서 두 측정 구간 중 어느 쪽도 2026년 양산차의 독립 실측값으로 확인한 것은 없음
- **Q. $50,000을 내면 차값과 출고일이 정해짐?**
  - 확인한 금액은 미국 일반 예약금임. 최종 차량 견적이나 고객 인도 확약을 뜻하지 않음
- **Q. 뭘 보여줘야 이번 발표를 다르게 볼 수 있음?**
  - 고객이 받는 차의 사양, 재현할 수 있는 성능 검증, 구체적인 생산·인도 계획이 나오면 판단 근거가 훨씬 단단해짐
